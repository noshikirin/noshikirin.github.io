# Security

## Reporting a problem

Please don't open a public issue for security problems. Instead, report them
privately through GitHub:
[Report a vulnerability](https://github.com/noshikirin/noshikirin.github.io/security/advisories/new)

Helpful details: what you found, where (page or file), and how to reproduce it.

## Scope

This is a static site with no server code, accounts, or stored user data.
Relevant reports include things like exposed personal information or secrets,
insecure third-party content, or problems with the build and deploy workflow.
